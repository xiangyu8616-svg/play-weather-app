## 📱 如何预览

### 推荐：手机预览（Expo Go）

**第 1 步：下载 Expo Go**
- iPhone: App Store 搜索 "Expo Go"
- Android: 应用市场搜索 "Expo Go"

**第 2 步：扫描二维码**
Expo 服务器已启动，在终端中会显示二维码

**第 3 步：确保同一 WiFi**
手机和电脑连接到同一个 WiFi 网络
